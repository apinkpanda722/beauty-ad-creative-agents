## 한계

- **표본이 1건이다.** 연결과 경로 확인이지 정확도나 비용 분포가 아니다. 이 비용($0.00058)을 1,500건으로 곱해 견적으로 쓰지 않는다(소재 길이와 호출 종류가 다르고, 분석 견적은 시범 직후 `cost-recalc`가 계산한다).
- 모델이 고른 `hook_type` 값은 모델 출력이라 이 문서에 정확도 근거로 적지 않는다(E1에서 측정한다).
- 종료 코드는 사용자 출력에 포함되지 않았다(`STOPPED`·`PREFLIGHT_FAILED` 줄이 없음으로 정상 종료를 추정했다).
- `timeout=` 인자(P1 step 5의 "첫 live 확인 대상")는 호출이 정상 완료돼 문제가 없었음을 시사하지만 실제 시간 초과가 발생한 경우는 검증하지 못했다.
