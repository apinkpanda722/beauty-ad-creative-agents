### 8.1 비교 1: terra `reasoning_effort` (`complete: true`, 장부 합계 $0.08123)
모델 `gpt-6.1-terra`, 입력 5건 × 값 3개 = 15호출, 모든 호출 첫 시도 성공(구조화 실패 0).

| effort | 쓸 수 있는 기획안 수 | 구조화 실패 | 호출당 비용 | 호출당 추론 토큰 | unknown 평균(`unknown_count`) |
|---|---|---|---|---|---|
| `none` | 4/5 | 0 | $0.004133 | 0 | 3.0 |
| `low` | 5/5 | 0 | $0.004798 | 149.8 | 3.2 |
| `medium` | 5/5 | 0 | $0.007315 | 457.2 | 4.0 |

- **판정(§3 규칙 그대로)**: 쓸 수 있는 기획안 수 최다는 `low`·`medium`(5/5) 동률 → 구조화 실패 수 동률(0) → 낮은 비용 `low`. 결정: **권고 `low`**(보류 조건 3/5 미만은 해당 없음). `none`의 쓸 수 있는 기획안 4/5는 입력 3의 기획안이 쓸 수 있는 조건을 못 채운 것이다.

- **한계**: 입력 5건·값마다 1회 호출이라 통계적 근거가 아니다(개발 결정용). `unknown_count`가 평균 3.0~4.0으로 높고 입력 4에서 특히 높다(10·12·16). "근거 연결 없음"이 많다는 뜻이며 기획안의 효능 근거가 검증됐다는 뜻이 아니다. 비용은 사전 추정(§5의 $0.07~0.12)의 안이다.

### 8.2 비교 2: sonnet 구조화 출력 (a) 대 (b) (`complete: false`, 장부 합계 $0.065664, 상한 $0.10 안)

### 8.4 sonnet `thought_tokens` 관찰 (오프라인 점검, 모델 호출 없음)
- (a) 호출에서 `thinking`을 요청하지 않았는데(step 0 규칙: haiku·sonnet에 `reasoning_effort`·`thinking`을 보내지 않는다) 장부 행 9건 중 3건에 `thought_tokens` 153·250·222가 있었다. 3건 모두 **재요청(두 번째 시도) 호출**이고 첫 시도 호출은 0이다.
- **비용 반영**: 가격표 비용은 `output_tokens` 전체를 출력 단가($10/M)로 계산한다. 세 행 모두 장부 `cost_usd`가 손계산과 일치한다(예: 입력 2,490·캐시 읽기 660·출력 345 → $0.007176). `thought_tokens`는 별도로 더하지 않는다. 이 세 행의 `output_tokens`에서 `thought_tokens`를 빼면 192·308·194로 `thought_tokens`가 없는 행의 출력(222~312)과 같은 크기라, **`output_tokens`가 추론 토큰을 이미 포함**한 것으로 보인다(추론 근거이며 공식 문서 조회로는 확인하지 못했다: Extended thinking 문서 페이지에 `usage.output_tokens`의 정의가 없었다). 따라서 가격표 수정은 필요하지 않고 `thought_tokens`는 `output_tokens`의 부분집합인 참고 칸으로 읽는다.
- **원인 미확인**: 요청하지 않은 추론이 재요청에서만 나온 이유는 확인하지 못했다(이번 기록의 한계). 비용에는 이미 반영돼 있다.
