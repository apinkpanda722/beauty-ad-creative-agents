## 7. 알려진 한계

1. **근거 소재 풀이 얇다**: 비교 도구의 축별 소재 수 합이 7건 규모였고, 지배 값의 점유율이 5~16%에 그쳤다(9c 이후 기획안 3건의 `pattern_alignment.share` 관측 7개 값: 0.05·0.05·0.09·0.14·0.14·0.14·0.16, 계산 불가 2건). 이 규모에서는 "지배 패턴과 다르게" 요구가 의미 있는 대비를 만들지 못하고 평가자의 차별성 판단도 불안정하다.
2. **강제 대비 위험**: 지배 패턴과 달라야 한다는 지시는 점유율이 낮은 축에서도 무리한 대비를 만들 수 있다. 9e에서 점유율 기준 이상인 축에서만 요구하도록 완화하고 얇은 풀이면 코드가 한계를 `basis_notes`에 적는다(기준값은 잠정, 사용자 승인 전).
3. **소넷 평가 첫 시도 실패**(위 5절): 비용·지연 2배, 원인 미확정.
4. **이미지 라벨 글자 부정확, 메타 문구 혼입**(위 6절): 생성 시안은 참고용이다(결과 화면 고지 칸은 9e).
5. `pattern_alignment`의 같은 패턴 여부(`same`)는 9c 이후 기획안 3건의 모든 축에서 거짓이었다(`compared` 3). 보고용 지표이며 판정에는 쓰지 않는다.
6. 개발 반복 결과(dev workspace, 2~5건): 일반화·최종 평가 근거로 쓰지 않는다. test 브랜드(isntree·beauty_of_joseon) 최종 평가 전에 프롬프트·기준값을 동결한다(`docs/PROMPT_CHANGELOG.md`).

## 8. 시안 확인에서 추가로 지적된 점(사용자 확인, 9c 이후 image 실행)

- 헤드라인 "세안 후, 어떤 세럼을 고르세요?"가 한국어 광고 카피로 부자연스럽다.

- 소넷 평가가 첫 시도에 항상 실패해 평가가 두 번 호출되고 비용·시간이 약 2배였던 것이 9e 이후 사라졌다(0/8). luna·terra는 계속 첫 시도 실패 0.
- **가설의 한계**: 9d에서 실패 경로·종류 집계를 넣고 9e에서 평가 `rationale`을 "한국어 200자 이내"로 지시문에 명시한 뒤 사라졌으므로 길이 제한 초과가 원인이었을 가능성이 크다. 그러나 9d 이후에는 실패가 한 번도 관측되지 않아 `first_attempt_failure_details`로 **원인을 직접 확인하지 못했다**. 호출 수가 20 미만이라 우연일 가능성도 배제하지 못한다.

### 9.6 이미지 변화

- 9b 이전: 상한 오류로 이미지 미생성. 9b 뒤 첫 이미지는 3×3 스토리보드 콜라주였고 "글자 없음" 지시를 무시한 한글 자막·찌그러진 라벨이 그려졌다(사용자 확인).
- 9e: `image_prompt`에서 `hook_text`·메타 문구 제거, 무글자·무라벨 고정 지시 추가. 9f: 카피 글자를 코드가 폰트(Pretendard OFL)로 합성. 9g: `image_prompt`가 `image_brief`만 쓰고(영상 여러 장면 `scenes` 제외) 단일 컷 지시를 더함, 합성 레이아웃 축소. 9h: 합성 띠 제거(그림자 + 결정적 대비 보정), CTA 제거, 하단 중앙 제품명 한 줄(브랜드 프로필 값 + 그래프 `Product.name_ko`).
- 결과(사용자 육안 확인, 2026-11-18): 단일 컷·이미지 안 글자 없음·띠 없는 헤드라인·하단 제품명 한 줄·CTA 부재, 기준 통과로 판단.
- 대비 보정 기록(13:09 image): `contrast_adjusted` 참, `min_contrast` 3.872(기준 3.0 이상, 어두운 글자 또는 그라데이션 보정이 적용됨).
- 이미지 비용: 생성 1건당 약 $0.034.

## 10. 제품 정체성 결정과 후속 후보(2026-11-18)

- 사용자 확인: 합성 이미지에 제품 정체성이 없고 검은 띠·"자세히 보기" CTA가 불필요하다는 지적. 대응(step 9h, live 미검증): 띠 제거, CTA 기본 끔, **B안** — 코드가 브랜드(프로필 영문 표기)와 제품명(그래프 `Product.name_ko`, 용량 제외)을 하단 중앙에 한 줄로 합성. 이미지 프롬프트는 무라벨 일반 병 그대로.
- **후속 후보(P7에서 시간이 남을 때, 지금 하지 않음)**: **C안** — 실제 제품 사진을 참조 이미지로 이미지 모델에 넣어 제품 외형을 반영한다. 제품 사진의 저장·재배포 금지 규칙(AGENTS.md: 이미지 파일은 분석 후 삭제, 공식몰 이미지 저장·재배포 금지)과 충돌하므로 별도 설계·승인이 필요하다.

## 11. 알려진 한계(최종)

1. **생성 이미지는 참고용이다**: 이미지 모델은 무라벨 일반 병을 그리고 제품 외형이 실제 제품과 다를 수 있다. 결과 화면 데이터에 고지 칸(`design_disclaimer`: "생성 시안은 참고용이며 라벨 글자가 부정확할 수 있다")이 있다. 이미지 안 글자는 코드가 합성한 헤드라인·제품명 한 줄뿐이다.
2. **소재 풀 규모와 분포**: dev 풀은 169~398건이고 축별 1위 점유율이 0.26~0.51로 뚜렷한 지배 패턴이 없는 축이 많다. 차별성 판단의 신뢰도는 풀이 얇은 카테고리에서 낮을 수 있다(`thin_pool` 기준 10건 미만은 이번 관측에 없었다).
3. **효능 검사는 확인만 한다**: 제품·성분·효능 연결이 확인되는지만 보고 부당 광고 여부는 판정하지 못한다(고지 문구 노출).
4. **소넷 첫 시도 실패의 원인 미확정**: 9d 이후 실패가 관측되지 않아 상세 집계로 확인하지 못했다(9.5).
5. **프롬프트·척도가 바뀐 뒤의 점수는 이전과 직접 비교하지 않는다**: `prompt_versions`로 구분한다. 점수 상승이 차별성의 실제 개선이라는 증거가 아니다(평가 기준 변경).
6. **dev 반복 결과**: 요청 수가 적고 test 브랜드(isntree·beauty_of_joseon)가 아니다. 일반화·최종 평가 근거로 쓰지 않는다.
