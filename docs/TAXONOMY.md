# 소재 분류 목록 (초안 v0)

> 상태: 초안. 값 목록과 정의는 라벨링 시범(20건)을 거쳐 고친 뒤 v1로 동결한다. 동결 뒤의 변경은 ADR에 남긴다.

## 원칙

1. **관찰 가능한 사실만 라벨로 쓴다.** "매력적인가" 같은 판단이 아니라, 영상을 본 누구나 같은 답을 내는 항목만 둔다.
2. **값은 닫힌 목록이다.** 자유 텍스트를 받지 않는다. 어디에도 안 맞으면 `other`를 쓰고 사유를 남긴다. `other` 비율이 10%를 넘는 축은 목록을 고친다.
3. **구간을 고정한다.** 훅은 첫 3초, 구조는 전체 영상을 기준으로 판정한다.
4. **축마다 하나만 고르는지, 여럿을 고르는지 정해 둔다.**
5. **화면과 음성에 실제로 나온 것만 적는다.** 손만 보이는데 성별을 적거나, 분위기에서 효능을 추정하지 않는다.
6. **모델 출력은 번역하지 않고 원문 그대로 저장한다.**

## 출처

실무 퍼포먼스 마케팅에서 소재를 변수로 쪼개 테스트할 때 쓰는 축(앵글·훅·포맷·크리에이터·오퍼)과, 플랫폼이 공개한 크리에이티브 가이드를 따른다.

|---|---|---|
| 구조(훅·본문·마무리), 훅 구간, 행동 유도, 자막, 출연자 | TikTok "Creative Codes: 6 principles"(ads.tiktok.com/business/en-US/blog/creative-best-practices-top-performing-ads). 4번 원칙 "three-part structure consisting of a hook, body, and close", "90% of ad recall impact is captured within the first six seconds", 텍스트 오버레이 권장, CTA 카드, 크리에이터 협업 | 원문 확인(2026-11-12) |
| 앵글, 훅, 포맷, 출연자, 오퍼 | 크리에이티브 테스트 프레임워크의 변수 분해와 광고 이름 규칙(storyflow.so/ad-creative-testing: 앵글 목록 problem·desire·objection·comparison·social proof, 이름 규칙 date_product_angle_hook_format_creator_version) | 검색 결과 본문으로 확인(실무 업체 자료라 공식 기준은 아님) |

## 축과 값

### 0. 콘텐츠 유형 `content_type` (하나 선택, 다른 축보다 먼저 판정)

| 값 | 판정 기준 |
|---|---|
| `product_creative` | 특정 제품을 보여주거나 설명하는 것이 중심이다 |
| `event_place` | 매장·팝업·행사·협업 공간 안내가 중심이다 |
| `brand_campaign` | 특정 제품 없이 브랜드 메시지·모델·캠페인을 보여준다 |
| `other` | 공지, 채용, 일상 등 |

`product_creative`만 아래 축으로 분석한다. 나머지는 콘텐츠 유형과 지표만 그래프에 넣는다. 시험 호출에서 목욕탕 협업 팝업 홍보 영상이 제품 소재처럼 억지로 분류된 것을 막기 위한 단계다.

### 1. 훅 유형 `hook_type` (하나 선택, 첫 3초 기준)

| 값 | 판정 기준 (첫 3초 안에 관찰되는 것) |
|---|---|
| `question` | 화면 자막이나 음성이 의문문으로 시작한다 |
| `problem` | 피부 고민 상태를 화면으로 보여주거나 말로 제시한다 (트러블, 건조, 모공 등) |
| `result_first` | 사용 후 결과나 사용 전후 비교가 먼저 나온다 |
| `bold_claim` | 수치·순위·단정 문장이 자막이나 음성으로 나온다 ("1위", "7일 만에") |
| `product_first` | 제품 용기·제형 클로즈업으로 시작하고 위 네 가지에 해당하지 않는다 |
| `person_first` | 인물이 등장해 말하거나 행동하며 위 다섯 가지에 해당하지 않는다 |
| `other` | 위 어느 것도 아니다 |

타이틀·로고 화면으로 시작하는 영상을 어디에 넣을지는 미정이다. 시범 라벨링에서 빈도를 보고 `title_card` 값을 추가할지 정한다.

둘 이상 해당하면 표의 위쪽 값을 우선한다. 시범 호출에서 같은 영상이 `question`과 `problem`으로 갈렸던 것을 이 우선순위로 정리한다.

| `ingredient_science` | 성분·작용 원리 설명이 중심이다 |
| `how_to` | 사용법·루틴 시연이 중심이다 |
| `other` | |

| `other` | |

### 4. 출연자 유형 `talent` (하나 선택)

`none`, `ordinary_person`, `creator`, `celebrity`, `expert`, `staff`

- `celebrity`와 `creator`는 영상만으로 구별하기 어렵다. 캡션·제목의 이름 표기나 협업 표기가 있을 때만 붙이고, 없으면 `ordinary_person`으로 둔다.
- 시범 영상(토리든 × 아이돌 협업)에서 모델이 협업 사실을 놓쳤다. 캡션·제목을 함께 입력해 판정한다.

### 5. 구조 `structure` (각 항목 예/아니오, 영상 전체에 그 장면·구간이 있으면 true)

> 아래 정의는 시범 라벨링을 위한 **초안**이다(조언 세션 작성). 시범 라벨링 뒤 v1 동결 전에 확정한다.

| 칸 | true인 경우 | false인 경우(예) |
|---|---|---|
| `has_hook_segment` | 초반(첫 3~5초)에 시선을 붙잡으려는 의도적 장치가 있다: 질문, 고민 제시, 놀라운 결과 장면, 큰 주장, 강한 시각 연출 | 로고·타이틀 화면으로 천천히 시작, 제품만 가만히 비춤 |
| `has_demo_segment` | 제품을 실제로 쓰는 동작이 보인다: 바르기, 펴 바르기, 마스크 붙이기, 뿌리기 | 제품 용기·제형 클로즈업만 있고 쓰는 동작은 없음 |
| `has_proof_segment` | 효과를 입증하려는 근거가 나온다: 사용 전후 비교, 수치(%·일수), 테스트·인증 결과, 수상·순위, 후기 인용 | "촉촉해요"라고 말만 하고 근거는 없음 |
| `has_cta` | `cta_type`이 `none`이 아니다. 영상·제목·캡션에 구매 요청, 더 알아보라는 안내, 판매처 표기, 할인·행사 표기, 참여 유도 중 하나가 있다 | 해시태그만 있음, 브랜드 소개만 있음 |

`hook_type`은 훅이 어떤 유형인지, `has_hook_segment`는 훅 구간이 있는지다. `hook_type`을 `other`가 아닌 값으로 골랐다면 보통 `has_hook_segment`는 true다.

- **미확정 쟁점**: 시범 라벨링에서 `hook_type`이 `product_first`인데 `has_hook_segment`가 false인 경우가 20건 중 6건(P001·P003·P004·P007·P009·P013)이었다. 위 "보통 true" 문장과 `product_first`의 정의가 충돌한다. v1 동결 때 `has_hook_segment` 정의를 확정하거나 이 축을 제거할 근거로 삼는다.

- **미확정 쟁점**: `has_cta` ⇔ `cta_type`이 `none`이 아님(판매처·할인·행사 표기도 CTA로 센다)은 조언 세션이 정한 임의 규칙이다. 처음 초안("구체적 행동을 요청하는 말")은 `store_mention`·`event`와 모순돼 고쳤다. 확정 필요.

### 6. 플랫폼 적합성 `platform_fit` (각 항목 예/아니오)

> 아래 정의는 시범 라벨링을 위한 **초안**이다. 시범 라벨링 뒤 v1 동결 전에 확정한다.

| 칸 | true인 경우 | 비고 |
|---|---|---|
| `is_vertical` | 화면이 세로로 길다(대략 9:16, 4:5) | 가로(16:9)와 정사각형은 false. YouTube 일반 영상은 대개 false, 쇼츠는 true |
| `has_text_overlay` | 편집으로 화면 위에 얹은 글자가 있다: 제품명, 효능 문구, 가격, 장식 문구 | 제품 포장지에 인쇄된 글자와 말소리를 옮긴 자막은 여기 넣지 않는다 |
| `has_voice` | 사람 말소리가 있다: 내레이션, 대화, 인터뷰 | 노래 가사는 말소리로 치지 않는다 |
| `has_music_only` | 말소리 없이 음악·효과음만 있다 | `has_voice`와 동시에 true일 수 없다. 완전 무음이면 둘 다 false |
| `has_subtitles` | 말하는 내용을 옮긴 자막이 있다 | 말을 옮긴 글자는 subtitles, 말과 무관한 문구는 text_overlay. 둘 다 true일 수 있다 |

### 7. 행동 유도 `cta_type` (하나 선택, `has_cta`가 false면 `none`)

> 아래 정의는 시범 라벨링을 위한 **초안**이다. 시범 라벨링 뒤 v1 동결 전에 확정한다.

| 값 | 뜻 | 예 |
|---|---|---|
| `none` | 행동 유도가 없다 | |
| `shop_now` | 구매하라는 직접 요청 | "지금 구매하기", "장바구니", "링크에서 구매하세요" |
| `learn_more` | 더 알아보라는 안내(구매를 직접 요구하진 않음) | "프로필 링크 확인", "자세히 보기", "댓글에서 확인" |
| `store_mention` | 판매처 이름만 알린다(구매 명령 없음) | "올리브영 입점", "Sephora에서 만나보세요" |
| `event` | 할인·증정·기간 한정·이벤트 참여 | "1+1", "쿠폰", "응모하면 추첨", "11월 한정" |
| `follow_engage` | 팔로우·좋아요·댓글·저장·공유·챌린지 참여 유도 | "팔로우하고 댓글 남기기" |

- **미확정 쟁점**: 여러 개가 나오면 영상에서 가장 마지막에 요구하는 것을 고른다는 규칙은 조언 세션이 정한 임의 규칙이다. 확정 필요.

### 8. 소구점 `claims` (여럿 선택)

> 아래 정의는 시범 라벨링을 위한 **초안**이다. 시범 라벨링 뒤 v1 동결 전에 확정한다.

| 값 | 이런 표현이 나오면 |
|---|---|
| `hydration` | 보습, 수분, 촉촉, 건조함 해결 |
| `soothing` | 진정, 민감 피부, 붉은기 완화, 자극 완화 |
| `brightening` | 미백, 화사, 톤업, 잡티, 칙칙함 개선 |
| `firming_elasticity` | 탄력, 쫀쫀, 리프팅, 처짐 |
| `pore_sebum` | 모공, 피지, 블랙헤드, 번들거림 |
| `acne_trouble` | 여드름, 트러블, 뾰루지, 트러블 흔적 |
| `barrier` | 피부 장벽, 장벽 강화·회복(세라마이드 등 장벽 언급) |
| `anti_aging` | 주름 개선, 안티에이징, 노화 |
| `sun_protection` | 자외선 차단, SPF·PA 표기 |
| `texture_finish` | 효능이 아니라 사용감(제형·마무리감): 끈적임 없음, 산뜻, 보송, 빠른 흡수, 윤광·매트 마무리감 |
| `other` | 위에 없는 효능(각질 제거, 영양 등) |

- 자막이나 음성으로 **명시된** 효능만 붙인다. 화면 분위기에서 추정하지 않는다.
- **미확정 쟁점**: 조언 세션의 작업용 규칙은 영상 자막·음성을 기준으로 하되 캡션 본문 문장에 명시된 것도 인정하고 해시태그만 있는 경우는 제외한다. 위 원문("자막이나 음성")과 다르므로 캡션 문장을 인정할지 확정 필요.
- 이 값 목록은 온톨로지 1층의 효능(Efficacy) 노드와 같은 목록이다. 한쪽을 바꾸면 다른 쪽도 같이 바꾼다(`docs/ARCHITECTURE.md`의 온톨로지).
- 값 목록 중 미백·주름 개선·자외선 차단은 기능성 화장품 효능(식약처)과 같은 이름을 쓴다. 나머지(보습, 진정 등)는 기능성이 아니라 일반 화장품 효능이며, 어떤 표현이 금지·조건부 허용인지는 「화장품 표시·광고 관리 지침」 본문을 읽고 표현 규칙 노드로 옮긴다. 기능성 효능을 기능성 인증 없는 제품에 쓰는 것은 「화장품법」 제13조와 시행규칙 [별표 5]의 금지 대상이다(안내서 정독으로 확인, 값별 대응은 ADR-014).

### 9. 성분 `ingredients` (여럿 선택, 열린 목록)

자막·음성·제품 표기에 나온 성분명을 원문대로 추출하고, 그래프에 넣을 때 표준 이름으로 묶는다(예: "센텔라", "시카", "병풀" → `centella_asiatica`). 이 축만 열린 목록이다. 제품 라인 이름(예: "Hyalu-Cica")이 성분으로 잘못 뽑힌 사례가 있어, 표준 성분 사전과 대조해 사전에 없는 값은 버린다.

### 10. 제품 카테고리 `category` (하나 선택)

`mask_pack`, `serum_ampoule`, `sun_care`, `other`

- 1차 범위는 앞의 세 가지다. `other`로 분류된 소재는 수집은 하되 분석 대상에서 뺀다.

## 라벨링 검증 절차 (1인)

1. 소재 50건을 **모델 결과를 보기 전에** 사람이 먼저 라벨링한다.
2. 같은 50건을 7일 뒤, 첫 라벨을 가리고 다시 라벨링해 축별 본인 일치도를 낸다.
3. 분석 모델과 다른 회사 모델에 같은 기준서를 주고 라벨링시켜 사람·모델 A·모델 B의 일치도를 따로 보고한다.
4. 일치도가 낮은 축은 정의를 고치거나 뺀다.

한계: 기준을 만든 사람과 검수한 사람이 같다. 결과 문서에 "1인 라벨링, 재검사 일치도 기준"으로 적는다.
